Perdido en la selva

Perdido en la selva es un videojuego de aventura y rompecabezas en el que debes encontrar la salida de una misteriosa selva resolviendo acertijos y eligiendo los caminos correctos.

Después de perderte, tendrás que explorar diferentes habitaciones, superar desafíos y tomar las decisiones adecuadas para escapar. Ten cuidado con cada puerta que elijas. Una decisión equivocada podría atraparte en un bucle infinito, obligándote a repetir el mismo recorrido una y otra vez.

Usa tu lógica, presta atención a tu entorno y descubre el camino que finalmente te llevará a la libertad.

¿Podrás encontrar la salida o permanecerás perdido para siempre?
